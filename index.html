개인이 사용하는 할 일 연결 도구

Personal Tasks Connector

구글 Tasks에 저장한 할 일을 본인의 Mac에서 Codex와 Claude로 읽고 관리하는 개인용 연결 도구입니다.

할 일을 관리하는 방법

사용자가 AI 앱에 요청하면, 설치한 연결 프로그램이 Google Tasks API를 사용해 할 일과 목록을 조회하거나 추가·수정·완료 처리합니다. 요청한 항목을 이동하거나 삭제하는 기능도 제공합니다.

구글 계정에 저장한 같은 할 일을 Google Tasks와 TaskMenu에서도 확인할 수 있습니다. 개인용으로 수정한 TaskMenu는 선택한 구글 캘린더 두 개의 오늘 일정을 한 화면에 표시하며, 할 일을 시간표에 끌어 놓으면 연결된 구글 캘린더 일정을 생성합니다. 일정 블록을 움직이거나 늘리면 시작·종료 시간을 수정합니다. 원래 할 일의 완료 상태는 Google Tasks에서 관리합니다.

구글 계정에 연결하는 방법

본인의 구글 계정으로 접근을 허용한 뒤 사용합니다. AI 연결 프로그램은 Tasks에 저장한 할 일과 목록을 읽고 관리하는 권한을 요청합니다. 수정한 TaskMenu는 추가로 캘린더 목록을 읽는 권한, 본인이 소유한 캘린더의 일정을 읽고 수정하는 권한, 로그인한 계정의 이메일을 확인하는 권한을 요청합니다. 앱은 로컬 설정에서 지정한 업무·일상 캘린더 두 개를 사용합니다.

정보를 처리하는 방법

구글에 로그인할 때 받은 연결 정보는 본인의 Mac에 저장합니다. 수정한 TaskMenu의 접근·갱신 토큰은 macOS 키체인에 저장합니다. 요청한 작업에 필요한 할 일 정보는 사용자가 선택한 AI 앱에 전달됩니다.

접근하는 정보와 저장·전달 방식을 설명한 문서 읽기

이 페이지는 개인용 연결 도구의 목적과 정보 처리 방식을 설명하는 정적 문서입니다. Google, OpenAI, Anthropic이 제공하는 공식 앱이 아닙니다.
