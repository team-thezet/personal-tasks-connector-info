개인용 연결 도구 소개로 돌아가기

접근하는 정보와 처리 방식

이 문서는 Personal Tasks Connector가 구글 Tasks의 정보를 읽고 사용하는 방법을 설명합니다. 적용일은 2026년 10월 7일입니다.

구글에서 읽는 정보

연결한 계정의 할 일 목록과 할 일에 접근합니다. 작업에 필요한 목록 이름, 항목 제목, 메모, 마감 날짜, 완료 상태, 항목 식별자와 순서·상하위 관계를 읽거나 변경할 수 있습니다.

정보를 사용하는 목적

사용자가 선택한 AI 앱에서 요청한 할 일 조회·추가·수정·완료·이동·삭제 작업을 수행하기 위해 사용합니다. 설치한 연결 프로그램은 Google Tasks API로 해당 작업을 처리합니다.

정보를 저장하는 곳

실제 할 일은 사용자의 구글 계정에 저장합니다. 구글 로그인에 사용하는 클라이언트 정보와 접근·갱신 토큰은 본인의 Mac에 있는 개인 설정 폴더에 저장하며, 본인 계정만 파일을 읽을 수 있도록 설정합니다. 연결 프로그램은 필요한 경우 구글을 통해 접근 토큰을 자동 갱신합니다.

AI 앱에 전달하는 정보

요청한 작업에 필요한 할 일 정보는 사용자가 선택한 Codex 또는 Claude에 반환됩니다. 온라인 AI 모델을 사용하는 경우 해당 정보는 선택한 AI 제공업체로 전달되어 처리될 수 있으며, 해당 앱의 대화 기록이나 로그에 남을 수 있습니다. AI 제공업체의 정보 처리와 보관에는 해당 서비스의 정책 및 사용자 설정이 적용됩니다.

이 소개 페이지는 할 일을 받거나 저장하는 서버 기능을 제공하지 않습니다. 연결 프로그램의 구글 API 요청은 본인의 Mac에서 구글로 전송됩니다.

접근을 중단하거나 정보를 지우는 방법

본인의 구글 계정에서 연결한 앱을 관리하는 화면에서 이 연결 앱의 접근을 해제할 수 있습니다. 할 일 내용은 Google Tasks에서, AI 앱에 남은 대화와 로그는 해당 앱에서 관리합니다. 더 이상 연결을 사용하지 않을 때는 Mac에 저장한 로그인 파일을 삭제할 수 있습니다.

이 문서를 관리하는 곳

이 연결은 계정 소유자가 본인의 기기에서 사용하는 개인용 설정입니다. 구글 계정과 연결에 관한 문의 연락처는 구글의 권한 허용 화면에 설정한 지원 이메일입니다.

이 문서는 본인의 기기에 설치한 개인용 연결 설정의 정보 처리 방식을 설명합니다.
